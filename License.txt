
## **3. Инструкция по загрузке на GitHub**

```bash
# 1. Инициализируй git репозиторий
git init

# 2. Добавь все файлы
git add .

# 3. Сделай первый коммит
git commit -m "Initial portfolio website setup"

# 4. Создай репозиторий на GitHub (зайди на github.com и создай новый репозиторий с названием "portfolio")

# 5. Добавь remote origin (замени YOUR_USERNAME на твой GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git

# 6. Запуш изменения
git branch -M main
git push -u origin main
